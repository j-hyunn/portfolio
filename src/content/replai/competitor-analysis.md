# 경쟁사 분석

> Replai의 포지셔닝: "이력서와 면접을 하나의 흐름으로 잇는다"

## 시장 개요

면접·이력서 준비 도구는 네 카테고리로 나뉜다. v4.0에서 이력서 축이 추가되며 카테고리 2개가 새로 경쟁권에 들어왔다.

1. **AI 면접 연습 서비스** (직접 경쟁)
2. **AI 이력서 최적화 도구** (v4.0부터 직접 경쟁)
3. **채용 플랫폼 내장 AI 기능** (직접 경쟁 — 과거엔 간접으로 분류했으나 재분류)
4. 유료 컨설팅/코칭 (대체재)

---

## 1. AI 면접 연습 서비스

### 사람인 AI 모의면접 (한국) — 가장 직접적인 경쟁자

- **특징**: 구직자의 **이력서 및 지원 공고를 AI가 분석해 맞춤형 면접 질문 생성**. AI 휴먼 면접관과 대화형 진행
- **강점**: 답변에 따라 달라지는 **꼬리질문**, 답변·태도 피드백, **설득력 있는 예시 답변 제시**. 국내 최대 채용 플랫폼의 공고·이력서 데이터 보유. 플랫폼 내에서 지원까지 연결
- **약점 (추정)**: 사람인 생태계 안의 이력서 형식에 종속. 면접관 스타일 선택이나 커스텀 지침 같은 세밀한 제어는 확인되지 않음
- **Replai와의 관계**: **기능 중복도가 가장 높다.** "이력서 기반 맞춤 질문 + 꼬리질문 + 모범 답안"은 사실상 동일 명세다

### 하이잡 인터뷰 (한국)

- **특징**: 채용공고, 자기소개서, 기출·빈출 질문 기반 AI 면접 연습 앱
- **강점**: 모바일 앱, 기출 질문 DB
- **약점**: 자기소개서 중심이라 경력직 이력서·프로젝트 심층 검증에는 약할 가능성

### 잘봐요 (한국)

- **특징**: 2026·2027 공채 대비. 대기업·금융·공기업·IT 전 직무 인성·직무·PT 면접
- **강점**: 공채 시즌 타이밍 마케팅, 직무 커버리지 넓음
- **약점**: 공채 신입 중심. 경력 이직 맞춤은 약함

### Final Round AI (글로벌)

- **특징**: Interview Copilot(실제 면접 중 실시간 답변 제안), 모의면접, **AI 이력서 빌더**, 자동 지원
- **강점**: 실시간 보조가 강력. 이력서 + 면접 + 지원까지 한 번에
- **약점**: 한국어 지원 미흡. **가격이 매우 높다** (월간 $149, 연간 약 $500 수준)
- **참고**: 이력서 + 면접을 한 흐름으로 묶은 구조는 Replai와 같다. 포지셔닝 참고 대상

### Pramp (글로벌, 현 Exponent Practice)

- **특징**: 개발자 피어 투 피어 모의면접. 2021년 Exponent에 인수돼 운영 중
- **강점**: 실제 사람과의 코딩·시스템 디자인 인터뷰. 월 5 크레딧 무료 + 피어 피드백으로 크레딧 획득
- **약점**: 매칭 상대에 따라 품질 편차가 큼. 영어 위주. 이력서 맞춤 없음

## 2. AI 이력서 최적화 도구 — v4.0부터 경쟁권

JD를 붙여넣으면 이력서를 그에 맞게 다듬어주는 도구들. Replai의 제출용 이력서 생성과 직접 겹친다.

### 원티드 이력서 코칭 에이전트 (한국) — 국내 최대 경쟁자

- **특징**: 포지션에 맞춰 AI가 이력서를 분석하고 개선점 제시. **합격 이력서 샘플을 참고**해 개선. AI 제안을 **클릭 한 번으로 즉시 반영**. 이력서 내 AI 활용 경험 자동 추출
- **함께 출시된 것**: 포지션 검색 에이전트 (자연어로 조건 입력 → 적합 포지션 추천)
- **강점**: **실제 합격 이력서 데이터**를 학습 근거로 쓴다. 이력서 개선 → 포지션 추천 → 지원이 플랫폼 안에서 완결
- **약점 (추정)**: 원티드 이력서 포맷에 종속. 면접 연습 기능은 확인되지 않음
- **Replai와의 관계**: 이력서 축에서 가장 강한 경쟁자. **합격 데이터 자산은 Replai가 따라갈 수 없는 영역**

### 캐치 (한국)

- **특징**: **AI 자소서** — 클릭 3번으로 자소서 완성. 이력서를 갱신하고 'AI업그레이드'로 경력·강점 맞춤 자소서 생성. 이력서 기반 AI 매칭 공고 추천
- **강점**: 대기업·중견기업 채용 정보와 결합. 자소서 특화
- **약점**: 자기소개서 중심(경력기술서형 이력서는 상대적으로 약함). 대화형 면접 시뮬레이션 없음

### Teal (글로벌)

- **특징**: AI 이력서 빌더 + Job Tracker. **Matching Mode**로 JD에 맞춰 이력서 조정. 50+ 잡보드 연동
- **가격**: 무료 티어가 매우 관대 (이력서 무제한 + 트래킹 영구 무료), Teal+ 유료
- **강점**: 지원 파이프라인 관리가 강점. 무료 범위가 넓음

### Rezi (글로벌)

- **특징**: 23개 지표로 이력서 감사 후 1~100점 스코어링. **AI Keyword Targeting** — JD를 붙여넣으면 누락 키워드를 우선순위별로 실시간 표시
- **가격**: 월 $29 또는 평생 $149
- **강점**: 기술 직군 키워드 정확도가 높다는 평가

### Jobscan (글로벌)

- **특징**: ATS 키워드 매칭 특화. 이력서 빌더가 아니라 **키워드 매처**. 공고를 개인 매치 점수로 랭킹
- **가격**: 월 5회 무료, 유료 월 $49.95
- **강점**: ATS 통과 스코어링이 업계 기준급

## 3. 채용 플랫폼 내장 AI (재분류 — 이제 직접 경쟁)

| 플랫폼 | AI 기능 | Replai와 겹치는 축 |
|---|---|---|
| 사람인 | AI 모의면접(이력서+공고 기반 맞춤 질문·꼬리질문·예시 답변), AI 자소서 코칭 | **면접 + 이력서 양쪽** |
| 원티드 | 이력서 코칭 에이전트, 포지션 검색 에이전트 | **이력서** |
| 캐치 | AI 자소서, AI 매칭 공고, 기업용 픽챗 | **이력서(자소서)** |

과거 이 문서는 "사람인/잡코리아는 인적성 위주, 직무 기술 면접 부재"로 기술했으나 **이는 더 이상 사실이 아니다.**

## 차별화 재정의

기존 "JD + 이력서 기반 맞춤 질문"은 사람인이 커버한다. "JD 맞춤 이력서"는 원티드가 커버한다. **각각으로는 우위가 없다.** 남은 차별 지점은 셋이다.

### 1. 두 축이 하나의 데이터로 연결된다

사람인은 면접을, 원티드는 이력서를 각각 잘한다. 그런데 **"내가 이 회사에 실제로 낸 이력서로 그 회사 면접을 연습한다"**는 흐름은 어디도 완결하지 않는다. Replai는 마스터 이력서 → 제출용 이력서 → 그 이력서를 읽은 면접관까지 하나의 데이터로 이어진다.

> 단, 이 강점은 **사용자가 마스터 이력서를 실제로 작성해야** 발생한다. 7개 섹션 입력은 진입 장벽이다 — 이탈률 측정이 필요하다.

### 2. 면접관 스타일 제어

경험 탐색형 / 심층 압박형 / 기술 검증형 3종 + 페르소나별 커스텀 지침. 대형 플랫폼의 AI 면접관은 단일 스타일로 확인된다. "압박 면접 대비"처럼 목적이 명확한 연습은 Replai가 유리하다.

### 3. 플랫폼 종속이 없다 + BYOK

원티드·캐치·사람인의 AI는 그 플랫폼의 이력서 포맷과 공고 안에서만 동작한다. Replai는 어떤 회사 공고든 붙여넣을 수 있고, 사용자가 자기 API 키로 상위 모델을 쓸 수 있다.

### 구조적 열위 (인정해야 하는 것)

- **합격 데이터 없음** — 원티드는 실제 합격 이력서를 근거로 쓴다. Replai는 JD와 사용자 이력서만 본다
- **지원 연결 없음** — 플랫폼들은 연습 → 지원이 한 번에 끝난다. Replai는 연습만 하고 사용자는 다시 플랫폼으로 가야 한다
- **유입 경로 없음** — 채용 플랫폼은 구직자가 이미 매일 방문한다

## 포지셔닝 맵

```
                  이력서 + 면접 통합
                          │
              [Replai]    │    [Final Round AI]
                          │
낮은 비용 ────────────────┼──────────────── 높은 비용
                          │
  [Teal/Jobscan]  [사람인·원티드·캐치]  [컨설팅]
        (이력서만)   (플랫폼 내장)
                          │
                    단일 기능
```

Replai의 목표 좌표: **"Final Round AI의 통합성 + 무료"**

## 시장 기회

- 한국 IT 직군 채용 시장: 연간 수십만 건의 이직·취업 시도
- 서류 합격 후 면접 준비 기간: 평균 1~3주 — 다만 이력서 축이 추가되며 **진입 시점이 지원 전으로 앞당겨졌다**
- 대형 플랫폼의 AI는 각자의 축만 커버한다. **통합 흐름의 공백은 아직 남아 있다**

## 재조사 필요 항목

- 사람인 AI 모의면접의 꼬리질문 깊이·면접관 스타일 제어 여부 (직접 사용 필요)
- 원티드 이력서 코칭의 출력 품질 — 개조식 재작성 수준인지 문구 제안 수준인지
- 각 서비스의 무료 사용 한도 (Replai 무료 포지셔닝의 실효성 판단)
