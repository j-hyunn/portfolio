# 1. 목적 및 범위
---
### **1.1 목적**
- 팬 입장에서 유효한 티켓을 안전하게 거래할 수 있는 서비스의 **신뢰 기반 진입장벽을 낮추되**, 거래/정산 등 고위험 행위는 **필요 시 단계적으로 인증을 강화**한다.
- 주최/운영 관점에서 사기/분쟁/민원 리스크를 줄이기 위해 **사용자 식별의 최소 기준**을 확보한다.
### **1.2 In Scope 범위**
- 카카오 소셜 로그인 기반의 **회원가입/로그인**
- 최초 로그인 시 **필수 약관/개인정보 동의**
- 세션/토큰 관리(로그아웃, 토큰 갱신)
- 계정 상태 관리(정지/탈퇴/복구 정책)
- 기본 이벤트 로깅(분석/퍼널)

### **1.3 Out of Scope 범위**
- 본인인증(휴대폰 실명/계좌 인증 등) 구체 구현
    - 단, **거래 단계에서 추가 인증 필요**를 전제로 “연동 포인트”는 포함
# 2. 진입점
---
- 헤더
- 마이페이지
- 경기 상세 > 예매하기 버튼 인접 영역(로그인 유도)
- CTA 문구: **“카카오로 로그인”** 또는 시작 화면에서는 **“카카오로 시작하기”**
# **3. 사용자 시나리오**
- 유저 플로우
    
    ```mermaid
    flowchart TD
    	B[로그인 버튼 클릭]
    
      B --> C[카카오 인증 화면 이동]
      C --> D["동의 후 서비스로 리다이렉트 (Authorization Code 수신)"]
    
      D --> E["카카오 토큰 검증 및 사용자 정보 조회"]
      E --> F{"사용자 존재 여부 (kakao_user_id 기준)"}
    
      F -->|기존 사용자| G[세션 발급]
      G --> H["로그인 완료: 홈(또는 직전 페이지) 이동"]
    
      F -->|최초 사용자| I["내부 DB: 신규 사용자 생성"]
      I --> J["온보딩+데이터 수집 동의 및 마케팅 동의"]
      J --> K["로그인 완료: 홈 화면으로 복귀"]
    ```
    

---
### **3.1 최초 사용자(회원가입)**
1. 비로그인 상태에서 로그인 버튼 클릭
2. 카카오 인증 화면 이동 → 동의 후 리다이렉트
3. 서버가 카카오 토큰 검증 및 사용자 정보 조회
4. 내부 DB에 **신규 사용자 생성**
5. 서비스 약관/개인정보 처리방침/마케팅 선택 동의 > sns 로그인 시 동의로 간주
6. 로그인 완료 → 홈 화면으로 복귀
### **3.2 기존 사용자(로그인)**
1. 로그인 버튼 클릭 → 카카오 인증
2. 내부 사용자 조회(카카오 고유 ID 기반)
3. 세션 발급 → 로그인 완료
### **3.3 동의/프로필 변경 이슈**
- 카카오에서 이메일/닉네임 변경 가능 → 내부는 **카카오 고유 식별자**를 기준으로 계정 연결 유지
    - 이메일 변경 불가
    - 닉네임 칼럼 추가/수정 가능
- 사용자가 카카오 동의를 철회한 경우 → 로그인 실패 처리
# 4. 기능 명세
---
### **4.1 진입 화면**
- 화면: 로그인/시작하기
    - CTA: **[카카오로 시작하기]**
### **4.2 카카오 인증 → 서비스 리다이렉트**
1. 사용자가 [카카오로 시작하기] 클릭
2. 카카오 인증/동의 화면으로 이동
3. 동의 완료 시 서비스로 리다이렉트(Authorization Code 수신)
### **4.3 신규/기존 사용자 판별**
- 서버가 kakao_user_id 기준으로 사용자 조회
    - **기존 사용자**: 로그인 완료 → 홈(또는 직전 페이지) 이동
    - **신규 사용자**: 회원 생성(임시) → 온보딩(선호 조사) 진행
### **4.4 로그아웃 / 재로그인**
- 설정 > 로그아웃
- 로그아웃 시:
    - 로컬 세션 제거(Access/Refresh 폐기)
    - 서버 Refresh 토큰 폐기(회전/블랙리스트 방식 중 택1)
### **4.5 회원 탈퇴**
- 설정 > 회원탈퇴
- 탈퇴 전 고지:
    - 진행 중 거래/정산/분쟁이 있으면 탈퇴 제한 또는 “탈퇴 예약” 처리
    - 탈퇴 30일 유예
        - 30일 이내에 복구 원하면 고객센터 문의
        - 30일 내에는 재가입 불가
- 탈퇴 처리:
    - 사용자 상태 DELETED로 변경(소프트 삭제 권장)
    - 외부 식별자 연결 해제 정책
# 5. 정책
---
### **5.1 계정 식별 기준**
- Primary Key: **kakao_user_id(카카오 고유 식별자)**
- 이메일은 **식별 키로 사용하지 않음**(변경/미제공 가능)
### **5.2 필수 동의 항목(권장)**
- (필수) 서비스 이용약관 동의
- (필수) 개인정보 처리방침 동의
- (선택) 마케팅 수신 동의 > 온보딩에서 진행
※ 카카오 동의 항목(프로필/이메일 등)과 서비스 약관 동의는 구분한다.
### **5.3 연령/법적 요구**
- 성인 인증/연령 제한이 필요한 경우, 카카오 제공 정보로 부족
- 별도 KYC(휴대폰/계좌 인증 등)는 초기 Out of Scope
    - 단, **거래 단계 진입 시 추가 인증 연동 가능 구조**는 유지
### **5.4 로그아웃 정책**
- 서비스 세션만 종료
- 공용 기기 고려: “모든 기기에서 로그아웃” 옵션은 v2로 고려
### **5.5 탈퇴(계정 삭제)**
- 내부 계정 비활성화/삭제 정책(법적 보관 의무 고려)
- 카카오 연결 해제 처리
