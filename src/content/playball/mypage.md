# 1. 개요
---
### 1.1 목적
- 사용자가 계정/활동/티켓(티켓, 결제, 선호 데이터)을 한 곳에서 조회·관리한다.
- 예매 경험의 연속성을 위해 티켓 접근성(입장/공유/취소/환불/문의)을 최우선 제공한다.
- 추천좌석 기반 서비스 특성상 선호 데이터(온보딩 설문)를 언제든 수정 가능하게 하여 추천 정확도를 유지한다.
### 1.2 대상 사용자
- 로그인 사용자(카카오 소셜 로그인 기반)
### 1.3 진입 경로
- 헤더 마이페이지 버튼 / 예매 완료 후 CTA(“티켓 확인하기”)
# 2. 정보 구조(IA) 및 메뉴
---
- 프로필 요약(닉네임/프로필)
- **티켓 관리**
- **선호 데이터 수정**
- 결제/환불 내역
- 고객센터(FAQ/1:1 문의/공지)
- 약관/정책(이용약관, 개인정보 처리방침)
- 로그아웃 / 회원 탈퇴
# 3. 기능 명세
---
## 3.1 티켓 관리

### 3.1.1 티켓 목록(예매 내역)
> **목적:** 사용자가 보유/예정/지난 티켓을 한눈에 확인
- 기본 탭/필터
    - 예정된 경기(기본)
    - 사용 완료/지난 경기
    - 취소/환불
- 카드 표시 정보
    - 경기 일시, 경기장
    - 좌석 정보(구역/열/번호)
    - 상태 배지
        - **결제완료(확정)**: 정상 티켓
        - **결제대기(무통장)**: 입금 전
        - 취소 처리 중 : 티켓 취소 이후
        - 취소 완료 : 티켓 취소 완료
        - 환불 처리 중
        - 환불 완료
    - CTA:
        - 결제 완료 : “티켓 보기”, “예매 취소”
        - 결제 대기 : “결제 하기”, “예매 취소”
### 3.1.2 티켓 상세
> **목적:** 입장/공유/취소/문의 등 “티켓 액션”의 허브
- 기본 정보
    - 경기 정보(일시/대진/장소)
    - 예매 정보(예매번호, 예매일시, 매수, 총 결제금액, 결제수단)
    - 좌석 정보(구역/열/번호, 권종 구성)
- 티켓 표현(입장 수단)
    - **모바일 티켓(QR)** 노출
    - 보안 처리
        - 캡처 방지/워터마크
        - QR 갱신(유효 3분)
- CTA(상태별)
    - 결제완료: “좌석 보기(맵)” / “영수증”
    - 결제대기(무통장): “입금 안내 보기”
    - 취소가능 기간: “예매 취소/환불”
### 3.1.3 취소/환불
**목적:** 사용자가 규정 내에서 직접 취소를 진행
- 사용자 플로우
    1. 티켓 CTA, 티켓 상세 > “예매 취소”
    2. 취소 규정/수수료/환불 예정일 안내
    3. 동의 체크 > 취소 요청
    4. 결과 상태 업데이트(“취소 처리중/완료”)
- 표시 항목
    - 취소 가능 여부(기간/상태 기반)
    - 수수료/환불 금액 산정 결과
- **정책 확인 필요**
    - 취소 가능 시점(경기 N시간 전까지 등)
    - 부분 취소 지원 여부(일부 매수만)
    - 결제수단별 환불 처리 방식(간편결제/무통장)
### 3.1.5 결제대기(무통장) 전용 UX
- 입금 계좌/금액/기한, 예금주, 안내 문구
- 입금 확인
    - 자동 확인(가상계좌/PG 연동) vs 수동 확인(관리자 처리)
- 기한 만료 처리
    - 만료 시 티켓 상태 “결제실패/자동취소”로 전환 + 알림
## 3.2 선호 데이터 수정
### 3.2.1 목적/원칙
- 추천 정확도의 핵심 입력값이므로 마이페이지에서 언제든 수정 가능해야 함 
- 수정은 즉시 반영하되, 이미 생성된 주문/홀드에는 적용 안 함
### 3.2.2 진입 및 구성
- 마이페이지 메뉴: “선호 데이터 수정”
- 화면 구성
    - 현재 저장된 내블럭 목록 (최대 10개, 블록명 표시)
    - 현재 저장된 선호 데이터 요약
    - "수정하기" 버튼
### 3.2.3 입력 폼(온보딩 질문 재사용)
- **내블럭 수정**
- 경기장 블록 맵에서 현재 선택된 블록 표시
	- 블록 추가/삭제/재선택 가능 (최대 10개 제약 동일 적용)
	- 현재 선택 수 표시 (예: "7 / 10 선택")
- 온보딩 질문 세트 재노출 (기존 동일)
	- 각 질문별 1~3순위 선택 가능
### 3.2.4 저장 및 적용 범위
- 저장 동작
    - "저장" 클릭 시 서버에 최신 선호 데이터 + 내블럭 목록 업데이트
    - 성공 토스트: "내블럭 및 선호 데이터가 업데이트되었습니다"
- 적용 범위 정책
    - 저장 즉시 "새 추천(내블럭 정렬)"부터 반영, 기존 주문/홀드는 영향 없음
