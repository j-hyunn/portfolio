## 1. 추천의 목적과 원칙

플레이볼의 추천은 **"좋은 좌석을 찾아주는 기능"이 아니다.** 동일한 좌석에 수천 명이 동시에 몰리는 구조적 문제를 완화하여, **사용자가 좌석을 확보할 확률 자체를 높이는 것**이 목적이다.

- 추천은 사용자 선호를 반영하되, **Hold 성공 가능성**을 최우선 기준으로 삼는다.
- 추천 결과가 다시 특정 블록에 쏠려 2차 핫스팟을 만들어서는 안 된다.
- 추천은 보조 기능이다. 사용자는 언제든 맵 모드로 전환할 수 있다.

---

## 2. 추천 이용 조건

추천 모드는 아래 조건을 모두 충족한 사용자에게만 제공한다.

- 온보딩(선호 설문)을 완료했을 것
- 내블럭(선호 블록)을 1개 이상 등록했을 것

조건 미충족 시 추천 모드 진입을 차단하고 맵 모드로 안내한다.

---

## 3. 추천 블록 후보 선정 기준

### 3.1 기본 원칙

추천 후보는 **사용자가 온보딩에서 직접 선택한 내블럭(최대 10개)** 중에서만 선정한다. 플랫폼이 임의로 다른 블록을 추천 후보에 추가하지 않는다.

### 3.2 연석 가능 여부에 따른 후보 포함 기준

인원 수에 맞게 좌석을 확보할 수 없는 블록은 추천 후보에서 제외한다.

|인근 좌석 허용 설정|후보 포함 조건|
|---|---|
|OFF (기본)|같은 행에서 인원 수만큼 연속으로 빈 좌석이 있는 블록|
|ON|위 조건 충족 OR 1열 이내 인접 행에서 인원 수를 나눠 확보 가능한 블록|

> 인근 좌석 허용 토글은 경기 상세 페이지에서 사용자가 직접 설정한다.

---

## 4. 추천 정렬 기준

후보 블록은 아래 우선순위 순서로 정렬하여 노출한다.

**1순위 — 연석 확보 가능 수**

- 인원 수에 맞게 좌석을 묶을 수 있는 경우의 수가 많을수록 상위 노출
- 인근 좌석 허용 ON이면 인접 조합까지 포함하여 산출

**2순위 — 선호도 점수 (연석 수 차이가 작을 때만 적용)**

- 연석 확보 가능 수 차이가 작은 블록 간에는 선호도 점수로 순위를 결정한다.
- 연석 수 차이가 크면 선호도와 무관하게 연석 수 기준으로만 정렬한다.

**선호도 점수 구성 (최대 70점)**

|항목|내용|배점|
|---|---|---|
|관람 시야 선호|온보딩에서 선택한 뷰포인트 1순위 일치|30점|
||2순위 일치|20점|
||3순위 일치|10점|
|응원 구단 일치|내 응원 구단이 경기에 참여하고, 블록이 해당 팀 응원 구역일 때|25점|
|응원석 거리 선호|응원석 가까운 자리 선호 → 응원석 인근 블록에 가산|15점|
||응원석 먼 자리 선호 → 응원석 원거리 블록에 가산|15점|

> 선호도는 동점 상황의 tie-breaker 역할이며, 주 정렬 기준은 항상 연석 확보 가능성이다.

## 5. 추천 결과 노출 및 갱신 정책

### 5.1 노출 수

- 추천 블록은 내블럭 전체(최대 10개) 중 연석 가능한 블록만 노출한다.
- 노출 순서는 4절 정렬 기준을 따른다.

### 5.2 갱신 방식

- 예매 화면 진입 시 1회 계산하여 세션 동안 유지한다.
- 자동 갱신은 제공하지 않는다.
- 사용자가 새로고침 버튼을 누를 경우 잔여 좌석과 경합 상황을 반영하여 재계산한다.

### 5.3 추천 설명 표시 원칙

- 추천 이유는 "연석 가능", "경쟁 낮음", "선호 구역" 등 **2~3개 라벨**로만 표시한다.
- 점수 계산 방식, 순위 수치 등 내부 알고리즘은 사용자에게 노출하지 않는다.

## 6. Fallback 정책

추천이 정상 제공되지 않는 상황에서의 처리 기준이다.

|상황|사용자 안내|이후 처리|
|---|---|---|
|온보딩 미완료 또는 내블럭 없음|추천 기능을 사용하려면 선호 설정이 필요합니다|맵 모드 강제 전환|
|내블럭 전체 연석 불가 (매진 포함)|선택하신 블록이 모두 매진되었습니다. 좌석 맵에서 직접 선택해주세요|맵 모드 전환 + 추천 토글 비활성화|
|블록 선택 후 좌석 배정 실패|해당 블록의 좌석 확보에 실패했습니다. 다른 블록을 선택해주세요|다음 내블럭 카드 강조, 재시도 유도|
|새로고침 후 전체 블록 연석 불가|현재 추천 가능한 블록이 없습니다. 좌석 맵에서 선택해주세요|맵 모드 전환 + 추천 토글 비활성화|

---

## 7. 공정성 원칙

- 동일한 내블럭을 가진 사용자 간 블록 확보는 선착순으로 처리한다.
- 특정 사용자에게 일관되게 유리한 블록을 우선 노출하지 않는다.
- 내블럭은 플랫폼이 임의 배정하지 않으며, 사용자가 온보딩에서 직접 선택한 블록만 대상으로 한다.
- 선호도 점수는 동점 상황에서만 순위 결정에 영향을 주며, 연석 확보 가능성이 낮은 블록을 선호도가 높다는 이유로 상위 노출하지 않는다.
