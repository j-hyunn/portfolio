## 2. 비회원 진입 차단 정책

### 2.1 예매하기 클릭 시 (경기 상세)

- **트리거**: 비로그인 상태에서 "예매하기" CTA 클릭
- **처리**: 로그인 유도 바텀 시트 또는 모달 노출
    - 문구: _"예매를 계속하려면 로그인이 필요해요."_
    - CTA: `[카카오로 로그인]` / `[닫기]`
- **로그인 완료 후**: 직전 경기 상세로 복귀, 예매 플로우 재개 (토글·인원 설정값 유지 권장)
- **온보딩 미완료 신규 회원**: 로그인 완료 후 온보딩 강제 진입 → 완료 후 경기 상세 복귀

### 2.2 마이페이지 접근 시

- **트리거**: 비로그인 상태에서 헤더 마이페이지 버튼 클릭
- **처리**: 로그인 페이지 이동 또는 로그인 모달 노출
- **로그인 완료 후**: 마이페이지로 이동

### 2.3 URL 직접 접근 시 (딥링크/북마크)

- 회원 전용 경로(`/my`, `/my/*`, `/booking/*`, `/order/*`, `/onboarding`) 에 비로그인 접근 시 로그인 페이지로 리다이렉트
- 로그인 완료 후 원래 요청 경로로 복귀 (`redirect_uri` 파라미터 활용)
- 온보딩 미완료 상태로 예매 경로 직접 접근 시: 온보딩 강제 진입 후 예매 경로로 복귀

### 2.4 Hold/주문 세션 만료 시

- Hold 유효 시간(5분) 이내 세션 만료 시 Hold 자동 해제 후 경기 상세로 리다이렉트
- 결제 진행 중 세션 만료 시 결제 미완료 처리, 보유 Hold 해제, 경기 상세로 복귀 안내
