# 1. 문서 개요
---
### 1.1 목적
- 사용자가 **좌석 선택(추천/맵) 및 결제 단계로 진입하기 전**에 확인하는 **경기/구단 상세 정보**와 **예매 진입 제어 UI**를 정의한다.
- 동일 좌석으로 트래픽이 집중되는 문제를 완화하기 위해, 경기 상세에서 **추천좌석 ON/OFF 토글**을 제공하고, 추천좌석 사용 시 **예매 매수를 사전 확정**하여 이후 단계(추천/좌석맵)에서 일관되게 반영한다.
- 구단 상세에서 **구단 멤버십/연간 이용권 구매 페이지로의 진입**과 **경기 티켓 구매 진입**을 제공한다.
### 1.2 In scope
- **경기 상세**
    - 경기 기본 정보 노출(일시/장소/대진/가격 요약/판매 상태)
    - 추천좌석 보기 **ON/OFF 토글**
    - 추천좌석 ON 시 **예매 매수 설정**
    - “예매하기” 클릭 시 토글 상태에 따른 **좌석 선택 화면 초기 모드 결정**(추천 모드 vs 맵 모드) 및 파라미터 전달
- **구단 상세**
    - 구단 기본 정보 노출
    - 상단: **구단별 멤버십/연간 이용권 구매 페이지 진입**
    - 하단: **경기 목록 노출 및 예매 진입 제공**
### 1.3 Out of scope
- 좌석 선택 화면(추천 모드/맵 모드) 상세 UI 및 Hold/경합 처리(별도 티켓팅 본문 범위)
- 멤버십/연간 이용권 구매 플로우 상세(상품 상세/결제/발급 등)
- 비시즌인 케이스
# 2. 사용자 시나리오

### 2.1 경기 상세페이지(추천좌석 on)
1. 사용자가 경기 상세에 진입한다.
2. 추천좌석 토글을 **ON** 한다.
3. (선택) 예매 매수를 설정한다.
4. (선택) 원하는 가격대만 보기 토글을 **ON** 하고 가격 범위를 설정한다.
5. 예매하기를 클릭한다.
6. 좌석 선택 화면이 **추천 모드**로 진입한다(별도 문서 범위).
### 2.2 구단 상세페이지(추천좌석 off)
1. 사용자가 경기 상세에 진입한다.
2. 예매하기를 클릭한다.
3. 좌석 선택 화면이 **맵 모드**로 진입한다(별도 문서 범위).
### 2.3 구단 상세 → 구단 홈페이지 이동
1. 사용자가 구단 상세에 진입한다.
2. 상단 영역의 구단 홈페이지 CTA를 클릭한다.
3. 구단 홈페이지로 이동한다.
### 2.4 구단 상세 → 경기 예매 진입
1. 사용자가 구단 상세에 진입한다.
2. 하단의 경기 목록을 확인한다.
3. 특정 경기의 캘린더를 클릭한다.
4. 해당 **경기 상세**로 이동한다.
5. 경기 상세에서 토글/인원 수/가격대 설정 후 예매 진입한다.
# 3. 기능 명세
---
## 3.1 경기 상세페이지

### 3.1.1 화면 구성(UI)
- 경기 기본 정보 영역: 
	- 대진/일시/장소/가격 요약/판매 상태 
- **CTA 영역** 
	- 사용자 선호 구역 추천 토글: ON/OFF 
		- 설명 문구: "설정한 선호도에 맞는 구역을 먼저 보여드려요." - 인근 좌석 추천 토글: ON/OFF (ⓘ 안내 아이콘 포함) 
	- 인원 수 설정: 드롭다운 (1~10매) 
	- 내 선호 구역: 수정하기 버튼 - 예매하기 버튼 (상태별 문구/활성 제어)

### 3.1.2 사용자 선호 구역 추천 토글
- 노출: 항상 노출 (단, 미지원 경기 시 비활성 + 안내 문구) 
- 설명 문구: "설정한 선호도에 맞는 구역을 먼저 보여드려요." (토글 하단 고정 노출) 
- 동작: 
	- OFF: 예매 진입 시 좌석 선택 화면 맵 모드로 시작 
	- ON: 예매 진입 시 좌석 선택 화면 추천 모드(내블록 우선 표시)로 시작
### 3.1.3 인근 좌석 추천 토글
- 노출: 항상 노출 
- ⓘ 아이콘 클릭 시 툴팁 안내 문구 노출 
> 	해당 옵션을 킨 경우 4매 이상 구매 시 좌석 열을 분리하여 화보할 수 있습니다.
> 	  인근 좌석 허용 거리
> 	  * 같은 행
> 	  * 1열 이내
> 	  * 동일 블럭 내
- 동작: 
	- ON: Hold 실패 시 인근 블록에서 연석 자동 재시도
	- OFF: Hold 실패 시 재시도 없이 실패 처리 - 기본값: ON
### 3.1.4 인원 수 설정 
- 노출 조건: 항상 노출 (토글 상태와 무관) 
- 입력 방식: 드롭다운 
- 검증: 
	- 최소 1매
	- 최대 10매
### 3.1.5 내 선호 구역 
- 노출: 항상 노출 
- 구성: "내 선호 구역" 라벨 + "수정하기" 버튼 -
- 동작: "수정하기" 클릭 시 모달 노출 > 경기장 랜더링에서 블럭 수정
### 3.1.6 예매하기(CTA) 상태 제어
- 예매중: 활성, 클릭 시 예매 진입
- 오픈예정: 비활성, 오픈 예정 시간 카운트다운 노출
- 매진: 비활성, “매진” 노출
- 판매종료: 비활성, “판매 종료” 노출

### 3.1.7 예매 진입 시 전달 파라미터 예시
- matchId (필수) 
- initialMode = RECOMMEND | MAP (필수)
- partySize (필수)
- nearbyFallbackEnabled (인근 좌석 추천 토글 상태)
### 3.1.8 예외/오류 처리
- 네트워크 오류/데이터 로드 실패: 재시도 + 오류 안내 
- 정책 변경으로 인원 수 상한 변동: 값 보정 + 안내 노출 
### 3.1.9 VQA 튜토리얼
- 노출: 경기 상세 하단 예매 영역, 상시 노출 (판매 상태 무관)
- 구성
    -  안내 문구: "예매 전 이미지 보안 인증을 미리 체험해보세요."
	- CTA 버튼: `[보안 인증 체험하기]`
- 동작
    - `[보안 인증 체험하기]` 클릭 시 VQA 모달 노출
    - 모달 내 VQA는 실제 예매 시와 **동일한 문제 유형 및 통과 기준**으로 진행
    - 시도 기회는 **최대 3회**이며, 3회 이내 통과 시 통과 / 3회 모두 실패 시 실패 처리
    - 체험 결과는 실제 예매 진입·Hold·대기열에 영향을 주지 않음
    - 모달 하단 고정 안내: "이 체험 결과는 실제 예매에 반영되지 않아요."
- 예외/오류 처리
    - 문제 로드 실패(네트워크 오류): 모달 내 재시도 버튼 노출, 예매 진입 차단 없음
    - 모달 외부 클릭 또는 닫기 시: 진행 상태 초기화
## 3.2 구단 상세페이지

### 3.2.1 화면 구성(UI)
- 상단:
    - 구단 정보
        - 구단 로고
        - 구단 명
        - 구장
        - 올해 구단 성적
            - 순위 / WDL / 승률 / 타율 / 평균 자책 / 승차
        - **멤버십/연간 이용권 진입 CTA**
- 하단:
    - **필터 영역**
        - 전체/홈/어웨이
    - **경기 목록** + 경기별 CTA(경기 상세 페이지로 이동)
### 3.2.2 상단 CTA
- 동작: 클릭 시 구단별 홈페이지로 이동
### 3.2.3 하단 경기 목록
- **구성 형태**
    - 하단 경기 목록은 **월간 캘린더 형태**로 노출
    - 상단에 **연/월** 표시 및 이전/다음 월 이동 버튼(좌/우 화살표)을 제공한다.
    - 요일 헤더(일~토)를 고정 노출한다.
    - 캘린더 셀을 클릭하면 해당 경기 상세페이지로 이동
- **캘린더 셀(일자 카드) 노출 데이터**
    - 상단
        - 날짜 + 경기 시작 시간
    - 중앙
        - 상대 구단 정보(로고 + 구단명)
        - 월요일 “경기가 없어요” 표시
    - 하단
        - 경기 상태(판매 상태 / 경기종료 여부)
        - 상태에 따른 CTA 또는 상태 라벨
- **셀 상태 정의 및 UI 규칙**
    - **경기 없음**
        - 해당 날짜에 경기가 없으면 “경기가 없어요” 문구를 노출한다.
        - 클릭 비활성화
    - **경기 종료(과거 경기)**
        - 과거 날짜 또는 종료된 경기는 “경기 종료” 라벨을 노출한다.
        - 클릭 비활성화
    - **판매 예정(오픈 전)**
        - 예매 오픈 전 경기: “판매 예정” 라벨 노출
        - 클릭 시 경기 상세로 이동
    - **매진**
        - 매진 경기: “매진” 라벨 노출
        - 클릭 비활성화
    - **예매 가능**
        - 클릭 시 경기 상세로 이동
- **동작**
    - 월 이동(좌/우 화살표) 시 해당 월의 캘린더 데이터를 조회/갱신한다.
    - **캘린더 셀 클릭 :** 경기 상세 페이지로 이동한다.
    - 경기 종료 상태는 동작 없음.
- **제약/검증**
    - 과거 날짜(오늘 이전)의 “예매 가능” 상태는 존재할 수 없으며, 존재 시 **경기 종료로 강제 표기**한다.
# 4. 정책
---
### 4.1 추천좌석 토글 기본값
- 기본값: **OFF** (사용자가 의도를 명시하도록 유도)
- 사용자 토글 ON 설정 시 설정값 유지
### 4.2 예매 매수(인원 수) 정책
- 최소: 1
- 최대: 10
- 기본값: 1 / 설정 변경 시 변경값 저장 후 기본 노출
- 추천 모드 진입 시 partySize 전달 필수
### 4.3 구단 상세 예매 진입 라우팅
- 기본: 구단 상세 → 경기 상세 → 예매 진입
### 4.4 가격 필터 정책
- “원하는 가격대만 보기” 토글 기본값: on
- 토글 ON 시 minPrice/maxPrice 범위를 필터로 적용
- 가격 기준: “**1매 기준 가격**”으로 표기/적용
### 4.5 상태 저장(선택)
- 토글/매수 설정값 저장 범위:
    - 계정 기반 유지
