## 1. 문서 개요

### 1.1 목적
- 사용자가 예매한 티켓에 대해 **취소 요청 가능 시점, 수수료 산정 기준, 결제 수단별 환불 처리 방식**을 정의한다.
- 마이페이지 > 티켓 관리, 주문서/결제 화면의 취소·환불 UX 구현 및 CS 응대의 기준 문서로 활용한다.

### 1.2 In scope
- 취소 가능 기간 및 기준 시점
- 취소 수수료 구간 및 산정 방식
- 결제 수단별 환불 처리 절차 및 기간
- 무통장 입금 기한 및 미입금 자동 취소 정책
- 취소 불가 예외 케이스

### 1.3 Out of scope
- 구단/운영사 귀책 취소(우천 취소, 경기 중단 등) 환불 처리
- 쿠폰/프로모션 적용 건의 부분 환불 계산
- 부분 취소(일부 매수만 취소) — **미지원, 전체 취소만 가능**

---

## 2. 취소 가능 기간

### 2.1 기준 시점
- 취소 가능 여부는 **경기 당일 기준**으로 판단한다.
- **경기 당일은 취소/환불 불가**이며, 전날(D-1)까지만 취소 가능하다.

### 2.2 취소 수수료 구간

| 취소 시점 | 취소 수수료 |
|---|---|
| 예매일 포함 경기 7일 전까지 | 없음 (전액 환불) |
| 경기 6일 전 ~ 1일 전 | 티켓 금액의 10% + 예매 대행 수수료 |
| 경기 당일 | 취소 불가 |

- **"경기 N일 전"** 기준: 취소 요청 시각이 아닌 **취소 요청 날짜(자정 기준 0시)** 로 판단한다.
- 예매 대행 수수료는 예매 시 고지된 수수료 금액을 그대로 적용한다.

---

## 3. 결제 수단별 환불 처리

### 3.1 간편결제 (카카오페이 / 토스페이)
- 취소 요청 승인 즉시 환불 처리
- 실제 계좌/카드 반영은 카드사·PG 정책에 따라 1~3 영업일 소요될 수 있음 (플레이볼 처리는 즉시)

### 3.2 무통장 입금
- 취소 요청 승인 후 **영업일 3일 이내** 등록된 계좌로 환불금 입금
- 환불 계좌는 취소 요청 시점에 사용자가 직접 입력
- 처리 결과는 마이페이지 > 티켓 관리에서 상태 확인 가능

---

## 4. 무통장 입금 기한 및 자동 취소

### 4.1 입금 기한
- **일반 예매**: 예매 완료 익일(+1일) 23시 59분까지
- **경기 당일 예매**: 경기 시작 3시간 전까지
	- 경기 시작 3시간 이후 무통장 입금 결제 불가

### 4.2 미입금 자동 취소
- 입금 기한 초과 시 주문 상태를 **자동 취소**로 전환
- 자동 취소 시 수수료 없이 전액 환불 처리 (입금 미완료 상태이므로)
- 자동 취소 전 알림 발송 (타이밍은 별도 알림 정책 따름)

### 4.3 입금 전산 반영 시간
- 입금 후 전산 반영까지 약 **20분~1시간** 소요될 수 있음
- 반영 전 상태는 마이페이지에서 "결제 대기" 로 노출

---

## 5. 취소 불가 케이스

| 케이스 | 사유 |
|---|---|
| 경기 당일 취소 요청 | 당일 취소 정책 |
| 이미 사용된 티켓 (QR 인증 완료) | 입장 처리 완료 |
| 취소 처리 진행 중인 건 | 중복 요청 방지 |

---

## 6. 부분 취소 정책
- **미지원**: 동일 주문 내 일부 매수만 선택적 취소 불가
- 취소는 **주문 단위 전체 취소**만 가능
- 2매 이상 예매 후 일부만 취소하려는 경우 → 전체 취소 후 재예매 안내
