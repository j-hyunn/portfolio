## 1. 테스트 전 사전 준비

### 1.1 테스트 계정 세트

|계정 유형|설명|수량|
|---|---|---|
|신규 가입 계정|온보딩 미완료 상태 (`onboardingRequired: true`)|2개|
|온보딩 완료 계정|내블럭 설정 완료|3개|
|유효 티켓 보유 계정|BOOKED 탭 티켓 있음|1개|
|무통장 입금 대기 계정|입금 대기 티켓 있음|1개|
|취소 가능 기간 내 티켓 (경기 7일 전 이상)|수수료 0원 취소 검증용|1개|
|취소 수수료 발생 구간 티켓 (경기 1~6일 전)|10% 수수료 검증용|1개|
|비로그인 세션|쿠키/localStorage 없는 시크릿 브라우저|1개|

### 1.2 테스트 경기 데이터

|경기 상태|용도|
|---|---|
|예매 오픈 + 대기열 발동 수준 트래픽|대기열/VQA 전 구간|
|예매 오픈 + 트래픽 낮음 (대기열 미발동)|직진입 시나리오|
|오픈 예정 (판매 전)|CTA 비활성 검증|
|매진|CTA 비활성 검증|
|판매 종료|CTA 비활성 검증|
|당일 경기 (결제 완료 티켓 있음)|당일 취소 불가 검증|

### 1.3 테스트 환경 / 브라우저

- PC: Chrome 최신, Safari 최신
- Mobile: iOS Safari, Android Chrome
- 동시성 테스트: 동일 브라우저 2개 탭 (다중 Hold 어뷰징 시나리오)
- 시크릿 창: 비회원 차단 테스트 전용
