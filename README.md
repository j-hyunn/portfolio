# Jehyun's PM Portfolio

Product Manager 포트폴리오 사이트 — GitHub Pages로 배포됩니다.

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS
- shadcn/ui

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

`main` 브랜치에 push하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
